Về hệ thống

Đây là giao diện web cho hệ thống phân loại hoa Iris. Frontend HTML/CSS/JavaScript gửi dữ liệu đến REST API được xây dựng bằng FastAPI. API sử dụng mô hình SVM đã được huấn luyện và lưu bằng joblib.
